## Store listing

**Name:** WasmCheat

**Summary** (132 characters max):

> Change any web app or browser game from an AI agent or a DevTools panel: run JavaScript, edit WebAssembly memory, keep it as a mod.

**Category:** Developer Tools

**Language:** English

**Description:**

> WasmCheat changes web apps and browser games running in your browser. It runs JavaScript in the
> page, reads and writes the memory of games built with WebAssembly (Unity, Godot, Emscripten, Rust),
> and keeps a change as a mod that comes back every time the page loads.
>
> Open DevTools on the game's tab and choose the WasmCheat tab:
>
> 1. Type a number you can see (your coins, your score) and press First Scan.
> 2. Change it in the game, type the new number and press Next Scan, until one address is left.
> 3. Click it, type a new value and press Write, or Freeze to hold it there.
>
> For a value you cannot read, like a health bar, scan with no value and narrow with Went up,
> Went down, Changed or Stayed the same. Values update live, and every change is written to a log.
>
> It also finds games inside iframes (YouTube Playables, itch.io) and Web Workers, and has
> watchpoints, function patches, pointer chains and a speed control for those who go further.
> An optional local server lets an AI agent use the same tools.
>
> WasmCheat collects nothing and connects to no server but your own computer. It is open source
> under the MIT license.
>
> Use it on games and programs you own or are allowed to test, not to cheat other players online.

## Privacy tab

**Single purpose:**

> Lets a person, or an AI agent they connect on their own machine, inspect and change a web app or game
> running in a page: its WebAssembly memory and its JavaScript, including changes kept to run on every
> load, for apps they own or may test.

**Permission justifications:**

| Permission | Why it is needed |
| --- | --- |
| Host access to `http://*/*` and `https://*/*` | The page agent must run in a page before the game starts, to see the WebAssembly modules it creates. The game can be on any site, and often in a cross-origin iframe. |
| `scripting` | Injects the page agent into a tab that was already open when the extension was installed, so the user does not have to reload by hand. |
| `tabs` | Names the tab the panel works on (title and address) and notices when that tab reloads or closes. |
| `storage` | Keeps the panel's theme, the mods the user chose to keep (their code and the game frame's origin), and the pairing token and port for the optional local MCP server. For the current browser session only, which tabs have the agent and the watchpoints and patches waiting for a reload. |
| `alarms` | Wakes the service worker every 30 seconds to reconnect to the optional local MCP server. |

**Remote code:** No. All JavaScript ships in the package. The Hooks and Script tools run code the
user types in the panel, or that their own local agent sends, in the page they are inspecting; it is
not fetched from anywhere, and every run is written to the audit log.

**Data usage:** the extension collects none of the listed data types. Certify all three
disclosures (no sale, no unrelated use, no creditworthiness use).

**Privacy policy URL:** https://github.com/alfman99/wasm-ce/blob/main/PRIVACY.md

## Review risks to expect

- **The name and purpose say "cheat".** Reviewers may question it. The single-purpose statement and
  the description frame it as inspecting your own programs, which is what the Policy section of the
  README says too. If it is rejected on this ground, a rename is the usual way through.
- **Broad host access** triggers an in-depth review and a slower first approval. It cannot be
  narrowed without breaking the main use: games load from any domain.
- **The Hooks and Script tools** run user-typed code with `new Function` in the page. Policy forbids remote
  code, not code the user types, but say so in the reviewer notes if asked.
