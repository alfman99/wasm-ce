                              Find a value, then change it
                              
            
          
                              
          
                              
            
                                
              
                              1. Approve the tab. Attach asks for permission once per tab and site. Nothing runs before you approve, and nothing runs after you revoke.
                                2. 
              
                              2. Read the instance list. Instances shows what Wasm modules the page loaded. Empty means the page has not started its game yet, or the game lives in a frame or worker; Diagnose in the Instances card says which.
                                3. 
              
                              3. Scan. Pick a type and a value you can see on screen, then First Scan. Play, watch the number change, type the new value and Next Scan. Repeat until one address is left.
                                4. 
              
                              4. Change it. Click the address, then Write, Freeze or Watch. Verify by reading the address back, not by trusting the page to redraw.
                                5. 
            
                              

            
                              The three numbers that matter
                              
            
                              
              
                              AddressA place in linear memory, written w1:0x408: instance, then byte offset. k1n1-1:0x408 is an instance inside a nested worker.
                              
              
                              TypeHow many bytes and whether they are signed. A value that will not match is usually the wrong width: try i64 or f64 before deciding the address is wrong.
                              
              
                              Scan idThe candidate list being narrowed. s1 is the page, k1-s1 is worker k1. Clear it and the list is gone.

                              When something is refused
                              
            
                              NEED_APPROVAL means the human has not approved this tab yet. NO_AGENT means the page agent is not running; Detach then Attach, or use Reload & attach. HOOK_EVAL_BLOCKED means the page forbids new Function, so use a declarative fallback instead of a hook body.
