                            Find a value, then change it
                            
            
          
                            
          
                            
            
                              
              
                            1. Open the panel on the game's page. That is the whole setup: the panel finds the WebAssembly by itself. If the page was open before WasmCheat loaded, it reloads it once to get in.
                              2. 
              
                            2. No instance? The game may not have started, or it lives in a frame or a worker. Open More tools, then Instances, and press Diagnose: it says which.
                              3. 
              
                            3. Scan. Pick a type and a value you can see on screen, then First Scan. Play, watch the number change, type the new value and Next Scan. Repeat until one address is left. For a value you cannot read, leave Value empty and narrow with Went up, Went down, Changed or Stayed the same.
                              4. 
              
                            4. Change it. Click an address in Found, type the new value, and press Write, or Freeze to hold it there. Games redraw a number when they change it, so the screen can lag behind memory.
                              5. 
            
                            

            
                            Three words to know
                            
            
                            
              
                            AddressA place in linear memory, written w1:0x408: instance, then byte offset. k1n1-1:0x408 is an instance inside a nested worker.
                            
              
                            TypeHow many bytes and whether they are signed. A value that will not match is usually the wrong width: try i64 or f64 before deciding the address is wrong.
                            
              
                            Scan idThe candidate list being narrowed. s1 is the page, k1-s1 is worker k1. Clear it and the list is gone.

                            When something is refused
                            
            
                            NO_AGENT means WasmCheat is not in the page; press Reload page. HOOK_EVAL_BLOCKED means the page forbids new Function, so use a declarative fallback instead of a hook body.
